# Shapes

WPF-приложение для работы с геометрическими фигурами (чистая архитектура: Domain -> Application -> App).

## Демо

https://github.com/user-attachments/assets/39f7b561-db43-455e-86c8-16f31989b593

## Требования

- .NET SDK 8.0 или выше (проекты нацелены на net8.0 / net8.0-windows)

Проверить установленную версию:

```powershell
dotnet --version
```

## Запуск

```powershell
dotnet run --project Shapes.App
```

Восстановление зависимостей и сборка (при необходимости):

```powershell
dotnet restore
dotnet build
```
